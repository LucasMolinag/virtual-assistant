Google Calendar

Appointments stay on this phone until you connect. After that, Vella adds and edits the Google Calendar your Android phone already syncs.

  1. In Google Cloud, enable the Google Calendar API.
  2. Configure the OAuth consent screen and add your Gmail address as a test user.
  3. Create an OAuth client ID of type Web application.
  4. Under Authorized JavaScript origins, add
  5. Paste the client ID below and tap Connect.

Install on Android

  1. Open this app in Chrome on your phone. The address has to be https.
  2. Tap the Chrome menu, then Install app or Add to Home screen.
  3. Open Vella from the home screen and allow the microphone.

If the installed app will not hear you, use the microphone on the Android keyboard in the text field. That still sends the same commands.

Home screen widget

Install the Vella Android app and allow calendar access. Touch and hold the home screen, tap Widgets, and drag Vella agenda onto the screen. Use Week or Month on the widget. Each day lists its appointments underneath. Drag Talk to Vella on separately when you want to speak a change.
